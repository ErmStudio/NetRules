# Участие в проекте

Спасибо за интерес к NetRules!

## Как помочь

- **Нашли баг** — создайте issue с описанием, логами и версией KeeneticOS.
- **Есть идея** — issue с меткой `enhancement`.
- **Сделали улучшение** — pull request с понятным описанием.

## Правила для pull request

1. Не добавляйте секреты: токены, пароли, `ui.conf`, сгенерированные конфиги.
2. Shell-скрипты — POSIX sh (`sh -n script.sh` должен проходить).
3. Интерфейс — без внешних CDN, только локальные ресурсы.
4. Проверьте, что панель открывается и вкладки работают.

## Лицензия вкладов

Отправляя PR, вы соглашаетесь распространять его на условиях MIT (см. LICENSE)
и сохранять упоминание автора проекта.
