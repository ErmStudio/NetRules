## 1.9.3 — 2026-11-28

### Замер без вмешательства
- Замер скорости идёт через **отдельный порт 7893** (listener `speedtest` + группа `TEST`). Активный узел не переключается во время замера — загрузки и звонки не рвутся. Рабочий узел меняется один раз в конце, если найден быстрее.

### ITX как расширение
- Если второй подписки нет (`/opt/etc/itx/sub.json` отсутствует), панель **скрывает** карточки ITX, Google через ITX и выбор узла. Проект остаётся универсальным для одного провайдера.
- Признак отдаётся в `config` как `itx_available`.

## 1.7.0 — 2026-11-27

### Watchdog переписан
Причина прошлых перезапусков: сторож проверял здоровье через `/proxies/AUTO/delay`, а это заставляет mihomo тестировать все 227 узлов. Запрос не успевал, считался сбоем, mihomo перезапускался, а после трёх перезапусков за час сторож **снимал правила** — прокси фактически выключался.

Теперь:
- проверка — один запрос `204` через локальный прокси-порт (быстро и точно отражает работоспособность);
- при 3 сбоях — мягкое переключение на авто-выбор без перезапуска;
- перезапуск только при 6 сбоях, максимум 3 раза в час;
- правила **никогда не снимаются** автоматически;
- тест группы AUTO больше не используется.

## 1.0.0 — 2026-11-27

Первый публичный релиз.

### Возможности
- Панель на одной странице: обзор, скорость, сеть, сервис, правила, логи.
- Светлая и тёмная темы, сохранение выбора в браузере.
- Переключатели прокси, соцсетей, видео Google и zapret — с горячей перезагрузкой правил без разрыва соединений.
- Живые карточки: аптайм роутера и mihomo, CPU, RAM, узлы, трафик с графиком, обновление подписки.
- Сеть: соединения по устройствам (имена из DHCP Keenetic) и доменам, политика PROXY/DIRECT/REJECT.
- Пометка «висящих» доменов, фильтр «все / висящие / здоровые», массовый перевод в VPN.
- Проверка доступности домена напрямую с роутера.
- Замер скорости топ-5 узлов с закреплением лучшего, автозамер каждые 2 часа и после обновления подписки.
- Полная проверка всех узлов: живые/мёртвые.
- Страна фактического выхода и история задержки.
- Бэкапы конфигов с восстановлением из интерфейса.
- Учёт трафика по дням снапшотами каждые 15 минут (устойчив к перезапускам).
- Уведомления в Telegram о падениях узла и перезапусках.
- Конфигурация через `/opt/etc/mihomo/ui.conf`.
- Горячие клавиши: `1`–`6` — вкладки, `R` — обновить, `Esc` — закрыть окно.

### Технические детали
- Автозапуск S96–S99, watchdog с fail-safe, ротация логов.
- API на CGI без внешних зависимостей (POSIX sh + python3 для агрегации).
- Интерфейс без CDN: один HTML-файл с встроенными стилями и скриптами.
